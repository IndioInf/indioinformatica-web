# Indio Informática — prueba de catálogo y fichas técnicas

Versión estática de prueba para GitHub Pages. Incluye cinco productos de muestra (iPhone 16 base, iPad A16, iPad Air M4, MacBook Neo 512 GB y MacBook Air M5), imágenes locales suministradas para la tienda, descripciones comerciales, colores oficiales y fichas técnicas desplegables.

## Cómo probarlo localmente

1. Descomprimí la carpeta del proyecto.
2. Abrí `index.html` en el navegador. No necesita instalación ni dependencias externas.

## Cómo publicarlo en GitHub Pages

1. Subí el contenido de esta carpeta a la raíz del repositorio de prueba.
2. En GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama principal y la carpeta `/(root)`, y guardá.
5. Esperá a que GitHub Pages publique el sitio.

## Qué incluye

- Filtros por Todos, iPhone, iPad y MacBook.
- Descripción breve por producto.
- Colores oficiales con la leyenda **CONSULTAR COLOR DISPONIBLE**; no representa stock.
- Ficha técnica organizada por secciones, desplegable en la misma página.
- Las imágenes están guardadas dentro de `assets/productos/`; no depende de imágenes externas.
- No se muestran enlaces externos a las fuentes técnicas en las fichas.

## Pendientes antes de usar en producción

- Validar la configuración exacta que se venderá para cada SKU (por ejemplo, Wi‑Fi frente a Wi‑Fi + Cellular y distribución de teclado).
- Confirmar las imágenes y modelos finales con el inventario.
- Revisar cada ficha técnica antes de publicarla como ficha definitiva.
- Incorporar precios o medios de contacto únicamente cuando se acuerde el formato final.

Las especificaciones de esta muestra se contrastaron con las páginas de especificaciones de Apple disponibles al momento de prepararla. Este prototipo no incluye enlaces a dichas fuentes para el visitante.
